# Medical Deepfake Detection on Lung CT Images

Code and experimental results accompanying the thesis
"Robustness and Generalization in Medical Deepfake Detection:
A Study on Lung CT Images".

## Models
- EfficientNet-B0
- ConvNeXt-Tiny
- DWT + EfficientNet-B0

## Contents
- src/: model implementations and data processing
- scripts/: training and evaluation
- tests/: software tests
- results/: aggregated metrics and training histories

## Data availability
Medical datasets, individual predictions and model
checkpoints are not redistributed.
